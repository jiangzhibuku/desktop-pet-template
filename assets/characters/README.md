# Character packs

## Tracked in this repository

- `mochi/` — an **original placeholder character** generated by
  `tools/generate_placeholder.py`. It is released under **CC0-1.0** and is safe
  to use, modify and redistribute.

## Third-party packs

Do **not** commit character packs that you did not create or that are licensed
only for personal / non-commercial use.  This includes most "free" game-art
packs: free to use is not the same as free to redistribute.

Put your local packs in the user data directory instead:

```
%APPDATA%\DesktopPet\characters\<pack-name>\
```

The app searches that directory first, so the repository stays clean and the
pack is never pushed to GitHub.

> If a pack is licensed for redistribution (for example CC0 or an asset-store
> license that explicitly allows it), you may commit it **together with its
> license file and attribution** in the pack directory. When in doubt, don't
> commit it.

See [`docs/ASSETS.md`](../../docs/ASSETS.md) for the folder format, frame
naming rules and a licensing checklist.
