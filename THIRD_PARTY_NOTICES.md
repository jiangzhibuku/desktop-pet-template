# Third-party notices

## No third-party artwork or fonts are bundled

This repository ships **only** original placeholder artwork generated by
`tools/generate_placeholder.py` (CC0-1.0), plus the original application icon
and preview images generated from it.

It does **not** contain the character animation packs (`daiji`, `dazhao`,
`khqn`, `tiaoyue`) or the `ChillHuoFangSong` font used during the early local
prototype. Those files were third-party material with unclear or
non-commercial-only terms and must not be redistributed here.

If you add a character pack or font, you are responsible for its license. See
[`docs/ASSETS.md`](docs/ASSETS.md).

## External services

The optional chat / vision features send data to the API endpoint configured in
`config.json` (default: Zhipu AI / BigModel). Weather uses `wttr.in`. These
services have their own terms and privacy policies. No API key is included in
this repository.
