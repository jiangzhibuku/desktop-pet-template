# 使用说明 / Usage Guide

> Desktop Pet Template · 桌面宠物生成模板
> 一张图或一句话，生成会动、会聊天的 Windows 桌面宠物。
> Turn an image or a sentence into an animated Windows desktop pet.

**平台 / Platform:** Windows 10 / 11
**Python:** 3.10 – 3.12
**仓库 / Repository:** `https://github.com/jiangzhibuku/desktop-pet-template`

---

# 中文

## 1. 准备环境

需要：

- Windows 10 或 Windows 11
- Python 3.10 – 3.12（推荐 3.12）
- 可选：一个大模型 API Key（没有也能生成角色和显示动画，只是不能聊天）

检查 Python：

```powershell
python --version
```

## 2. 安装

### 方式 A：一键安装（推荐）

确认已经安装 Python 3.10–3.12，然后双击：

```text
install.bat
```

或者在 PowerShell 里：

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

脚本会自动检查 Python、创建 `.venv`、安装依赖，并询问是否安装 rembg。

### 方式 B：手动安装

```powershell
git clone https://github.com/jiangzhibuku/desktop-pet-template.git
cd desktop-pet-template

py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1

python -m pip install -U pip
pip install -r requirements.txt
```

如果 PowerShell 禁止激活虚拟环境：

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

也可以不建虚拟环境，直接用系统 Python 安装依赖。

### 方式 C：下载免安装版

如果维护者已经发布 Release，到 GitHub 的 **Releases** 下载：

```text
DesktopPet-v0.3.2-win64.zip
```

解压后双击 `DesktopPet.exe`，不需要安装 Python。

## 3. 先运行默认角色

```powershell
python run.py
```

也可以双击 `run.bat`，或在 PowerShell 里：

```powershell
.\run.ps1
```

第一次运行会在下面的位置生成配置：

```text
%APPDATA%\DesktopPet\config.json
```

默认角色是原创小猫 **Mochi**，不需要任何 API Key。

## 4. 操作方式

| 操作 | 效果 |
| --- | --- |
| 左键按住拖动 | 移动桌宠 |
| 左键双击 | 打开聊天输入框 |
| 右键单击桌宠 | 打开 8 项轮盘菜单 |
| `Esc` | 收起菜单 / 气泡 |
| 轮盘「创建」 | 生成新角色 |
| 轮盘「扩展」 | 管理允许 AI 打开的软件白名单 |

轮盘菜单包括：跳跃、散步、大招、聊天、待机2、创建、扩展、退出。

## 5. 生成自己的角色

### 5.1 用一句话

```powershell
python create_pet.py --name 雪球 --prompt "白色小猫，戴红围巾，蓝眼睛"
```

支持中英文，例如：

```text
橘色小狗，戴蓝色蝴蝶结
灰色兔子，戴圆眼镜，星星花纹
a black cat with green eyes and a red scarf named Midnight
```

当前离线绘制支持：

- 物种：猫、狗、兔、狐、熊、鸟、史莱姆
- 配饰：围巾、蝴蝶结、眼镜、帽子、耳机、小花
- 花纹：斑点、条纹、星星、爱心
- 颜色、眼睛颜色、名字提取

### 5.2 用一张图片

```powershell
python create_pet.py --name 小蓝 --image "C:\Users\你\Pictures\cat.png"
```

推荐：

- 透明 PNG 最好
- 角色完整、正面或微侧身
- 512×512 以上
- 脚底尽量在同一水平线

抠图方式：

```powershell
# 自动：透明通道 / 纯色泛洪 / 必要时 rembg
python create_pet.py --name 小蓝 --image .\cat.png --cutout auto

# 强制本地 rembg 智能抠图
python create_pet.py --name 小蓝 --image .\cat.png --cutout rembg

# 保留原图背景（JPG 会带矩形底）
python create_pet.py --name 小蓝 --image .\cat.png --keep-bg
```

### 5.3 用已有动画帧

```powershell
python create_pet.py --name 旧角色 --frames "D:\old\pet" --link
```

`--link` 只写绝对路径，不复制大文件。支持自动识别：

| 新名称 | 旧目录 |
| --- | --- |
| idle | `idle` / `daiji/daiji1` / `daiji1` |
| idle2 | `idle2` / `daiji/daiji2` |
| idle3 | `idle3` / `daiji/daiji3` |
| walk | `walk` / `khqn` |
| jump | `jump` / `tiaoyue` |
| ultra | `ultra` / `dazhao` |

### 5.4 用图形向导

1. `python run.py`
2. 右键桌宠 →「创建」
3. 填名字
4. 选「用文字描述」或「用一张图片」
5. 图片模式可点「上传图片」，选完立即预览
6. 选「抠图方式」
7. 点「生成并切换」

生成后在后台完成，桌宠会立即换角色，不需要重启。

## 6. 配置聊天 API Key

没有 Key 时：生成角色、动画、拖拽、菜单都能用；聊天会提示去配置。

编辑：

```powershell
notepad $env:APPDATA\DesktopPet\config.json
```

把：

```json
"api_key": ""
```

改成：

```json
"api_key": "你的新Key"
```

或者用环境变量：

```powershell
$env:DESKTOP_PET_API_KEY = "你的新Key"
python run.py
```

默认接口是智谱 BigModel 的 OpenAI 兼容端点，可改：

```json
"api": {
  "base_url": "https://open.bigmodel.cn/api/paas/v4",
  "model": "glm-4-flash",
  "vision_model": "glm-4v-flash",
  "image_model": "cogview-3-flash",
  "api_key": ""
}
```

也可换成 OpenAI、DeepSeek、本地 Ollama 等兼容服务。

## 7. 可选：本地智能抠图 rembg

复杂背景推荐安装：

```powershell
pip install "rembg>=2.0" onnxruntime
```

然后：

```powershell
python create_pet.py --name 小蓝 --image .\cat.png --cutout rembg
```

说明：

- 免费、离线，图片不出本机
- 首次使用下载约 170MB 的 `isnet-anime` 模型
- 适合二次元/角色立绘
- 模型下载失败、rembg 没装时自动回退泛洪，不会中断
- 打包 exe 时 rembg 会让体积增加几百 MB，可按需决定是否打包

## 8. 数据位置

```text
%APPDATA%\DesktopPet\
├── config.json
├── memory.json
├── todos.json
├── stats.json
├── whitelist.json
├── logs/operations.log
├── screenshots/
└── characters/<角色名>/
```

仓库里不含 Key、日志、个人截图或第三方动画。

角色包在：

```text
%APPDATA%\DesktopPet\characters\<角色名>\
```

包括 `character.json`、`preview.png`、`preview.gif`、`idle/ walk/ jump/ ultra/` 等。

## 9. 常见问题

**Q：`No module named kivy`**

```powershell
pip install -r requirements.txt
```

**Q：`No module named win32api`**

```powershell
pip install pywin32
```

**Q：启动后看不到桌宠**

先看终端报错；确认 Windows 10/11，远程桌面/虚拟机可能透明窗口异常。

**Q：宠物是黑底方块 / 全屏白底 / 白色剪影**

这是显卡或透明窗口兼容问题。v0.3.2 已默认使用 `angle_sdl2` 并修复色键；旧版可在启动前设置：

```powershell
$env:KIVY_GL_BACKEND = "angle_sdl2"
# 如果仍然异常，再试：
# $env:KIVY_GL_BACKEND = "glew"
```

远程桌面或禁用 DWM 的环境也可能出现类似问题。

**Q：聊天提示没有 API Key**

编辑 `%APPDATA%\DesktopPet\config.json`，或设置 `DESKTOP_PET_API_KEY`。

**Q：输入框不出现**

需要 Python 自带 `tkinter`。用 python.org 安装包通常已包含；Microsoft Store 版可能缺失。

**Q：JPG 去背景后还有白边**

安装 rembg 后用 `--cutout rembg`；或先用抠图工具输出透明 PNG；或调低 `--tolerance`。

**Q：rembg 第一次很慢**

首次下载约 170MB 模型；之后本地推理。

**Q：可以商用吗**

- 代码：MIT
- 自带 Mochi、图标、预览图、UI 背景：CC0
- 用户图片、旧动画、AI 出图：需自行确认授权

## 10. 平台与限制

- 只支持 Windows；macOS/Linux 未适配。
- 图片模式直接使用原图，不改变画风；真人照片转动漫需要图生图模型。
- 单张图的 walk/jump 是变换动画，不是骨骼动画。
- 离线文字绘制是风格化模板，不能画任意复杂设定。
- AI 聊天/出图需要用户自己的 API Key，可能产生费用。

## 5. Create your own character

### 5.1 From text

```powershell
python create_pet.py --name Snow --prompt "white cat with a red scarf, blue eyes"
```

Chinese and English prompts are supported. Offline drawing supports:

- Species: cat, dog, rabbit, fox, bear, bird, slime
- Accessories: scarf, bow, glasses, hat, headphones, flower
- Patterns: patches, stripes, star, heart
- Colors, eye color, and name extraction

### 5.2 From an image

```powershell
python create_pet.py --name Blue --image "C:\Users\you\Pictures\cat.png"
```

Recommended:

- Transparent PNG
- Full character, front or slightly angled
- 512×512 or larger
- Feet on a consistent baseline

Cutout modes:

```powershell
# Auto: alpha / flat-colour flood fill / rembg when needed
python create_pet.py --name Blue --image .\cat.png --cutout auto

# Force local rembg (requires installation)
python create_pet.py --name Blue --image .\cat.png --cutout rembg

# Keep the original background (JPG will show a rectangle)
python create_pet.py --name Blue --image .\cat.png --keep-bg
```

### 5.3 From existing frames

```powershell
python create_pet.py --name Legacy --frames "D:\old\pet" --link
```

`--link` stores absolute paths instead of copying large files. Recognised layouts:

| New name | Legacy folder |
| --- | --- |
| idle | `idle` / `daiji/daiji1` / `daiji1` |
| idle2 | `idle2` / `daiji/daiji2` |
| idle3 | `idle3` / `daiji/daiji3` |
| walk | `walk` / `khqn` |
| jump | `jump` / `tiaoyue` |
| ultra | `ultra` / `dazhao` |

### 5.4 From the GUI wizard

1. `python run.py`
2. Right-click the pet → **Create**
3. Enter a name
4. Choose **Text** or **Image**
5. In image mode, click **Upload image** (native file picker, instant preview)
6. Choose a cutout mode
7. Click **Generate & switch**

Generation runs in the background and switches the pet immediately.

## 6. Configure an API key

Without a key: character generation, animations, dragging, and menus work; chat will ask for a key.

Edit:

```powershell
notepad $env:APPDATA\DesktopPet\config.json
```

Set:

```json
"api_key": "YOUR_NEW_KEY"
```

Or use an environment variable:

```powershell
$env:DESKTOP_PET_API_KEY = "YOUR_NEW_KEY"
python run.py
```

The default endpoint is Zhipu BigModel's OpenAI-compatible API. You can switch to OpenAI, DeepSeek, local Ollama, etc. by changing `api.base_url` and `api.model`.

## 7. Optional: local rembg cutout

For complex backgrounds:

```powershell
pip install "rembg>=2.0" onnxruntime
python create_pet.py --name Blue --image .\cat.png --cutout rembg
```

- Free and offline; images never leave your machine
- First run downloads a ~170 MB `isnet-anime` model
- Good for anime / character art
- Falls back to flood fill if rembg or the model is unavailable
- Bundling it into an exe adds several hundred MB

## 9. Troubleshooting

**`No module named kivy`**

```powershell
pip install -r requirements.txt
```

**`No module named win32api`**

```powershell
pip install pywin32
```

**No pet visible**

Check the terminal output. Remote desktop / virtual machines may not support the transparent layered window.

**Black rectangle, white full-screen overlay, or white pet silhouette**

This is a GPU/transparent-window compatibility issue. v0.3.2 defaults to `angle_sdl2` and fixes the colour key. For older builds, set this before launching:

```powershell
$env:KIVY_GL_BACKEND = "angle_sdl2"
# If it still fails:
# $env:KIVY_GL_BACKEND = "glew"
```

Remote desktop or environments with DWM disabled can also cause this.

**Chat says no API key**

Edit `%APPDATA%\DesktopPet\config.json` or set `DESKTOP_PET_API_KEY`.

**Chat input does not appear**

The input box uses `tkinter`. The python.org Windows installer includes it; some Microsoft Store builds may not.

**JPG still has a white edge**

Install rembg and use `--cutout rembg`; or pre-cut the image to a transparent PNG; or lower `--tolerance`.

**rembg is slow the first time**

It downloads a ~170 MB model once, then runs locally.

**Can I use it commercially?**

- Code: MIT
- Bundled Mochi, icon, previews, UI background: CC0
- Your images, legacy animations, and AI-generated art: check their licences

## 10. Platform and limitations

- Windows only; macOS/Linux are not supported.
- Image mode uses the selected image as-is; photo-to-anime requires an image-to-image model.
- Walk/jump from a single image are transform animations, not skeletal animation.
- Offline text drawing is a stylised template, not arbitrary text-to-image.
- AI chat/image generation requires your own API key and may cost money.
